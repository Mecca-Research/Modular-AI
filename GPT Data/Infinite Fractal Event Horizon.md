## 1) What an event horizon is (the boring but sharp blade)

In general relativity, an event horizon is not a physical wall. It’s a **global causal boundary**: the set of points beyond which signals can’t reach future infinity. Locally, nothing special has to happen at the horizon (especially for a large black hole). The “dark plug” picture is a human-eye metaphor.

So if we want “fractal horizon,” we’re not changing the idea that **escape is impossible** (classically). We’re changing what we think the horizon *is doing informationally and geometrically*.

### (iii) What happens to unitarity and the Page curve?
